# Reporte Técnico: Arquitectura y Menús del Sistema (v6.36.0)

Este documento detalla la estructura actual del sistema Control Bolsas ERP, mapeando cada ruta, menú y submódulo disponible.

## 🧭 Estructura de Navegación Principal

La aplicación utiliza `react-router-dom` con carga diferida (`lazy`) para optimizar el rendimiento. A continuación, se detallan los módulos accesibles desde la barra lateral (Sidebar) y el ruteo interno.

### 1. Dashboard Maestro (`/`)
El centro neurálgico del sistema con visión global de la operación.
*   **KPIs Principales:** Total Vendido, Ganancia Comercial, Utilidad Líquida, Dinero en Tránsito, Cuentas por Cobrar, Estado de Caja Chica.
*   **Widget Proactivo:** Sugerencias basadas en facturas pendientes o atrasadas.
*   **Bandeja de Maquila:** Notificaciones en vivo de entregas reportadas por el fabricante (Andrés).
*   **Semáforo de Alertas:** Clasificación visual de deuda (Críticos >30 días, Urgentes, Recientes, Por Recoger).
*   **Herramientas Rápidas:**
    *   `Descargar Sábana Llena` (Excel)
    *   `Auditoría Maestra` (Link a `/audit`)
    *   `Cierre de Mes` (Exportación Excel)
    *   `Imprimir / Compartir Reporte` (Rentabilidad Comercial PDF)

### 2. Expedientes (`/ordenes`)
Módulo de gestión integral de ventas y facturación.
*   **Buscador Inteligente:** Filtro por cliente o número de folio.
*   **Flujo de Estados:** Visualización tabular de expedientes (Pedido, Revisión, Pendiente, Pagado, Recolectado).
*   **Nuevo Pedido Manual:** Creación de expedientes desde cero sin PDF.
*   **Modal de Expediente (`OrderModal`):**
    *   **Tab Resumen:** Detalle de artículos, totales, costos variables y comisiones.
    *   **Tab Facturas:** Registro de CFDI (XML) y desglose de cobro.
    *   **Tab Entregas:** Historial de eventos logísticos provenientes del fabricante.
    *   **Tab Imprimir:** Generación de Pre-Factura CFDI 4.0.

### 3. Seguimiento OC (`/oc`)
Vista diseñada para rastrear volúmenes contratados vs. entregados.
*   **Progreso Visual:** Barras de progreso que muestran kilos pedidos vs. surtidos.
*   **Alerta de Mermas/Sobrantes:** Identificación de diferencias logísticas con el cliente.

### 4. Tablero de Cobranza (`/cobranza`)
Pipeline Kanban interactivo para la gestión del flujo de efectivo.
*   **En Revisión (Gris):** Facturas enviadas, sin contrarecibo asignado.
*   **Por Cobrar (Azul):** Facturas con Contrarecibo, esperando pago de Providencia.
*   **Con el Contador (Amarillo):** Facturas pagadas por el cliente, esperando recolección física.
*   **En Caja Chica (Verde):** Dinero líquido ingresado a la caja operativa.
*   *(Soporta Drag & Drop con transacciones atómicas que afectan la CAJA).*

### 5. Compras y Logística (`/compras`)
Centro de control de abastecimiento con el fabricante (Andrés).
*   **Estado de Cuenta de Proveedor:** Saldo deudor o a favor con el fabricante.
*   **Entregas Atrasadas:** Listado de órdenes que sobrepasaron su fecha promesa de entrega.
*   **Registrar Llegada de Material:** Captura manual de kilos ingresados al almacén.
*   **Liquidar Deuda:** Acceso rápido para registrar un egreso de Caja Chica dirigido a pagar al fabricante.

### 6. CAJA (Caja Chica) (`/caja-chica`)
Libro mayor (Ledger) de movimientos en efectivo.
*   **Métricas de Liquidez:** Saldo actual, total de ingresos, total de egresos.
*   **Tabla de Movimientos:** Historial detallado de depósitos (recolección de contrarecibos) y gastos operativos.
*   **Registrar Movimiento:** Formulario de alta para ingresos/egresos manuales.

### 7. Catálogo (`/catalogo`)
Base de datos de productos para estandarizar las ventas.
*   **Listado de Productos:** Clave, descripción, precio unitario, costo, unidad de medida.
*   **Semáforo Predictivo:** Alertas visuales sobre la rentabilidad del producto.
*   **Alta y Edición:** ABM (Alta, Baja, Modificación) de artículos.

### 8. Importación de PDF (`/subir` y `/captura-rapida`)
Módulos de ingesta de datos.
*   **Subir Órdenes (PDF):** Extracción automatizada de datos desde Órdenes de Compra en formato PDF.
*   **Captura Rápida (Texto):** Parser inteligente para extraer folios y montos desde texto plano.

### 9. Configuración y Centro de Mando (`/centro-control`)
Ajustes globales del motor financiero.
*   **Reglas de Negocio:**
    *   Precio de venta base (MXN/kg)
    *   Costo de compra base (MXN/kg)
    *   Porcentaje de comisión contable
    *   Base de cálculo (Subtotal vs Total)
*   **Gestión de Accesos (Usuarios):**
    *   Invitación de nuevos administradores o visores.
    *   Control de roles (`admin`, `viewer`).

## 🔒 Rutas Especiales / Ocultas

### Portal Maquilador (`/portal-maquilador`)
*   **Propósito:** Interfaz externa para el fabricante (Andrés).
*   **Autenticación:** Requiere un PIN de acceso configurable.
*   **Funcionalidad:** Permite reportar kilos producidos y entregados sin dar acceso al resto del ERP financiero. Las notificaciones viajan al Dashboard Maestro.

### Mantenimiento y Logs
*   **Monitor Live (`LiveLogsModal` en Dashboard):** Feed estilo Matrix que muestra acciones de los usuarios en tiempo real.
*   **Auditoría y Sincronización (`/audit`):** Comparador de bases de datos para encontrar divergencias.
*   **Data Mining (`/mining`):** Reportes en crudo.

## ⚙️ Notas Arquitectónicas

1.  **Tecnología Base:** React 18, Vite, TypeScript, React Router.
2.  **Base de Datos:** Firebase Firestore con suscripciones en tiempo real (`onSnapshot`) centralizadas en un patrón *Context API* para minimizar lecturas de red.
3.  **Seguridad:** Backend protegido con `Cloud Functions` y `Security Rules` (Firestore/Storage) que validan el email verificado (`email_verified == true`) y el rol de usuario.
4.  **UI Framework:** Sistema CSS personalizado (Glassmorphism) + Framer Motion (Micro-animaciones). Ninguna dependencia externa pesada de componentes de UI.
